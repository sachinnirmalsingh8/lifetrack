# LifeTrack Premium v2.0

Your all-in-one money tracker & shopping companion.

## Features

- 📊 **Dashboard** — Balance, income, expense at a glance
- 💳 **Transactions** — Add income & expenses with categories
- 🛒 **Shopping List** — Smart categorization, suggestions, share list
- 📈 **Spending Insights** — Donut chart, category breakdown, tips
- 🎯 **Budget & Savings** — Monthly limits, savings goals with progress
- 🔄 **Recurring** — Auto-add monthly transactions (Rent, Salary, EMI)
- 📅 **Monthly Summary** — Month-wise income vs expense
- 📤 **Export CSV** — Download all transactions
- 🔥 **Streak Tracking** — Daily activity streak counter

## Tech

- Pure HTML/CSS/JavaScript — no frameworks
- LocalStorage for data persistence
- Mobile-first design (iPhone optimized)
- PWA ready
